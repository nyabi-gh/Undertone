## 이번 버전 (1.5.3)

- **이름이 다시 Mollu 로 돌아왔습니다.** 평소처럼 업데이트를 받으면 Mollu 가 설치되어 켜지고, Undertone 파일은 지워집니다. 설정과 API 키, 번역 캐시는 그대로 옮겨집니다. 우클릭 메뉴도 다시 **Mollu로 번역** 입니다.
- **Claude 로 번역할 때 가끔 번역이 빠지던 문제를 고쳤습니다.** Claude 가 번역 대신 원문을 그대로 돌려주거나 원문 뒤에 `Translation:` 같은 말을 덧붙여서, 아무것도 표시되지 않거나 영어 아래에 영어가 나오곤 했습니다. 이제는 번역만 받아서 보여 줍니다. 그동안 Claude 로 번역해 둔 문장은 이런 답이 섞여 있을 수 있어 한 번씩 다시 번역합니다.
- **번역이 실패해도 알아서 다시 시도합니다.** 네트워크나 서버 문제로 `번역 실패` 가 뜬 메시지가 화면에 있으면 1분 뒤 스스로 다시 시도합니다(최대 3번). API 키나 잔액 문제는 다시 시도하지 않습니다.

## 설치

1. 아래 **Mollu.plugin.js** 를 받습니다.
2. BetterDiscord 설정 → Plugins → **Open Plugins Folder** 에 넣습니다.
3. 플러그인 목록에서 **Mollu** 를 켭니다.

Undertone 을 직접 지우고 Mollu 를 새로 넣어도 설정은 옮겨집니다. 설정과 API 키 발급은 [README](https://github.com/nyabi-gh/Mollu#readme) 를 참고하세요. BetterDiscord 1.14.0 이상이 필요합니다. `Undertone.plugin.js` 는 1.5.x 버전의 자동 업데이트가 받는 파일이고, `.sig` 파일은 서명이라 받지 않아도 됩니다.

## In this version (1.5.3)

- **Undertone is Mollu again.** Take the update as usual. Once it lands, Mollu is installed and turned on, and the Undertone file is removed. Your settings, API keys and translation cache come along, and the right-click menu reads **Translate with Mollu** again.
- **Translations no longer go missing with Claude.** Claude sometimes sent the original back instead of a translation, or the original followed by a `Translation:` label, so a message showed nothing or English under English. Only the translation is taken from the answer now. Sentences Claude translated before this update may hold such answers, so they are translated once more.
- **A failed translation is tried again by itself.** When `Translation failed` shows up for a network or server problem, a message still on screen is tried again a minute later, up to three times. A refused API key or an empty balance is not retried.

## Installing

1. Download **Mollu.plugin.js** below.
2. Drop it into BetterDiscord → Settings → Plugins → **Open Plugins Folder**.
3. Enable **Mollu** in the plugin list.

Removing Undertone yourself and dropping Mollu in also keeps your settings. See the [README](https://github.com/nyabi-gh/Mollu/blob/main/README.en.md) for setup and where to get an API key. BetterDiscord 1.14.0 or newer is required. `Undertone.plugin.js` is what 1.5.x's updater downloads, and the `.sig` files are signatures; there is no need to download them.
